## So kannst du helfen

1. Wähle ein Material und prüfe, ob es noch aktuell ist.
2. Teile es auf Instagram, Facebook, LinkedIn, WhatsApp oder Discord.
3. Ergänze einen persönlichen Satz dazu, warum dir das Thema wichtig ist.
4. Füge den Link zum nächsten Protest oder zur Petition hinzu.
