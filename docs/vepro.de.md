# Aktiv werden

Jeder Beitrag zählt. Du musst nicht alles tun—schon eine einzelne Handlung hilft, die Stimmen der Bürgerinnen und Bürger hörbar zu machen. Hier sind vier konkrete Möglichkeiten.

<div class="grid cards" markdown>

-   :material-share-variant-outline:{ .lg .middle }

    ## 1. Teilen

    Hilf mit, Informationen, Materialien und Nachrichten mehr Menschen zugänglich zu machen.

    [Öffnen →](vepro/shperndaje.md)

-   :material-office-building-outline:{ .lg .middle }

    ## 2. An die Botschaft schreiben

    Schreibe der Botschaft der Republik Albanien und bringe deine Bedenken zum Ausdruck.

    [Öffnen →](vepro/ambasadat.md)

-   :material-account-tie-outline:{ .lg .middle }

    ## 3. An Abgeordnete schreiben

    Informiere deine Vertretung im Bundestag über die Entwicklungen in Albanien.

    [Öffnen →](vepro/deputetet.md)

-   :material-file-sign:{ .lg .middle }

    ## 4. Petition unterzeichnen

    Unterstütze unsere Forderungen, indem du die Petition unterzeichnest und teilst.

    [Öffnen →](vepro/peticioni.md)

</div>

## Was geschieht danach?

Je mehr Menschen Informationen teilen, Institutionen kontaktieren und die Petition unterstützen, desto stärker wird die öffentliche Aufmerksamkeit. Jede Handlung stärkt die zivilgesellschaftliche Stimme.
